## 🎯 Objetivo da Atividade

Este repositório contém os scripts SQL da Experiência Prática 4, cujo objetivo é:

- Implementar comandos SQL (DML) a partir do modelo lógico criado na EP3  
- Popular o banco de dados com dados reais (INSERT)  
- Executar consultas (SELECT) utilizando JOIN, WHERE, ORDER BY e LIMIT  
- Atualizar e remover dados (UPDATE e DELETE)  
- Utilizar GitHub como ferramenta de versionamento e entrega
